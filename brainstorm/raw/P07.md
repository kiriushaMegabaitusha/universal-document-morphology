## P07-1 — Turn persistence/appraisal from a named dimension into a coded layer

**[idea] One-sentence statement.** Code a fourth, page-independent
"record-life" layer (retention schedule · appraisal criteria · disposal /
transfer rule · legal-hold or permanent-value class) for all 28 systems, so the
persistence/appraisal dimension announced in finding 5 stops being a one-case
illustration (Nigeria) and becomes a variable that can be cross-tabulated
against the slot data and the regime classes.

**Mechanism / rationale (2–3 sentences).** [idea] The atlas names three regime
dimensions beyond the page — trace, access, persistence/appraisal
(`diversity.md` §10b) — but only *trace* has quantitative teeth (the S14
requisite counts); appraisal currently rests on `cases/ng.md` plus an
unstructured `custody/archive` keyword theme (16 case files in
`analysis/theme_matrix.csv`). Coding record-life regulation per system turns a
narrative aside into a testable layer, and the sharpest test it enables is
**orthogonality**: if page-format standards never specify retention while
archives/records acts never specify layout, the "kinds of document law"
catalogue is demonstrated to be disjoint layers rather than a list.

**[assumption] Assumptions.**
- A1: the already-retrieved case sources (`cases/ng.md`, `ke.md`, `za.md`,
  `vn.md`, `bj.md`, `se.md`, `ua.md`, `su` entries) state enough about
  retention/disposal to code presence/absence without buying any new corpus;
  a handful of targeted retrievals (archives acts, records schedules) may be
  needed for the rest.
- A2: hand-coding is acceptable here because the repo already discloses that
  its regime classes and era anchors are hand-assigned (`README.md` "Honest
  gaps"); the new layer inherits and repeats that caveat, and is declared
  non-derivable in `analysis/recompute.py` exactly like those tables.
- A3: missing knowledge is coded explicitly as `not found`, never as `absent`.

**[prediction] Predicted observations.**
- P1: page-format standards (DIN 5008, ДСТУ 4163, GB/T 9704, JIS) code 0
  record-life variables.
- P2: statutory archives/records regimes (NG, KE, ZA) and full
  delovodstvo decrees (UA №55, VN) code ≥3 of the 4 variables.
- P3: systems with functional document-type classification (SU / UA / RU line,
  `analysis/document_types.csv`) are the ones whose retention is expressible
  *by type* rather than by date-only rules.

**What would disconfirm it.** [prediction] Any page-format standard carrying an
explicit retention/disposal clause falsifies the orthogonality claim (P1);
finding no association between archives-act regimes and the coded variables —
after confirming it is genuine absence rather than `not found` — falsifies P2;
>1/3 of the 28 cells landing in `not found` disconfirms the *feasibility* of
the layer as a quantitative instrument and would demote it to a documented gap.

**Main feasibility risk.** Uneven, partly secondary source base for retention
schedules (the same grounding-tier problem the repo already flags for PE, HN,
ET, WA); mitigation is to publish the `not found` block openly and treat the
layer as ordinal (0–4), not interval. Compute: trivial (spreadsheet + a
small extension of the existing gate), weeks not months.

**Repo connections.** `README.md` key finding 5 + Honest gaps ·
`diversity.md` §10b, §12f · `EXECUTIVE_SUMMARY.md` ("kinds of document law",
three regime dimensions) · `analysis/theme_matrix.csv` (custody/archive = 16) ·
`analysis/qualitative_analysis.md` §6 (hand-coded caveat) · `STANDARDS.md`
Layer 2 (ISO 15489 / 16175 / MoReq — the abstract layer that never touches the
page) · `cases/ng.md`, `ke.md`, `za.md`, `vn.md`, `bj.md`, `se.md`.
**Not already done (checked):** searched root + analysis/ + cases/ for
retention/appraisal/disposal/transfer — appraisal appears only as prose in
`diversity.md` §10b and `cases/ng.md`; no CSV codes it; no `analysis/` output
cross-tabulates it.

## P07-2 — Independence audit: how much of the "convergence" rests on shared templates?

**[idea] One-sentence statement.** Systematically hash and near-duplicate-detect
every retrieved source text in `sources/` to measure how many nominally
independent systems' evidence is actually the same or a derivative of the same
template document, then re-run the slot-similarity analysis with
shared-template pairs flagged as a sensitivity check on the convergence claim.

**Mechanism / rationale (2–3 sentences).** [idea] The repo has already found one
byte-identical re-hosting by hand (the Saudi guide on a Qatar-hosted library,
MD5-identical — `diversity.md` §12b, `cases/ae.md`) and records "template
diffusion" as a theme for only 3 case files, but the check was never run across
the corpus. Normalized hashing plus shingling/minhash over the ~143 on-disk
files in `sources/` would find byte-identical, near-identical and
re-formatted copies cheaply; because the atlas's headline is *convergence across
independent traditions*, any clustering of evidence inside one template family
directly bears on whether that convergence is evidential or artefactual.

**[assumption] Assumptions.**
- A1: the texts in `sources/` correspond to the 60 ledger sources closely
  enough that duplicates found on disk indicate duplicates in `ledger.json`.
- A2: string-level similarity catches re-hosting and re-formatting (the
  known failure mode) but not translation into another language — so a null
  result licenses only the narrower claim "no re-hosted duplicates", which must
  be stated as such.
- A3: the convergence claim requires independence of *systems*, not of
  sources; one shared source spanning two systems is the unit of concern.

**[prediction] Predicted observations.**
- P1: at least one further identical or near-identical pair exists beyond the
  known Saudi/Qatar one.
- P2: any hits concentrate in the clusters with common ancestry (GOST-line
  texts, Francophone guides, UN/EU style-guide derivatives), not randomly.
- P3: flagging shared-template sources moves headline figures (slot census,
  S6⊥S9 fork) by little — ≤1 slot — because the fork rests on many systems;
  the interesting fork-affecting case would be a duplicate inside the two
  preamble-bearing systems (EU, UN), which are the whole support for S9.

**What would disconfirm it.** [prediction] A fully clean corpus (no new
identical/near-identical pairs at a pre-declared similarity threshold)
disconfirms the "phantom diversity" challenge and converts the exercise into a
published null that *strengthens* the evidence-base claim; a duplicate pair
that, once removed, changes a headline number by more than rounding
disconfirms the "sensitivity will be small" prediction instead.

**Main feasibility risk.** 15/60 sources are encyclopedia/secondary entries
with heavy boilerplate — false positives; mitigation is manual verification of
every hit above threshold (bounded: hits, not corpus) and reporting precision
alongside counts. Compute: minutes on CPU; no GPU, no budget.

**Repo connections.** `sources/` (143 files) · `ledger.json` (60 sources,
92 claims) · `diversity.md` §12b (the method lesson, already recorded) ·
`analysis/qualitative_analysis.md` §2 (template diffusion = 3 files) ·
`analysis/findings.md` §5 + `analysis/slot_similarity.csv` (the structure to
re-run) · `README.md` gate (`check_claims.py --online` is currently one-shot,
not comparative).
**Not already done (checked):** searched *.md for duplicate/MD5/fingerprint/
diffusion/re-host — only the single Gulf instance is documented; no script in
the repo compares source texts to each other; `check_claims.py` checks
citation resolution and URL liveness, not content identity.

## P07-3 — Migration-survival audit: which parts of the "deep grammar" actually survive a format change?

**[idea] One-sentence statement.** Classify all 225 requisites in
`requisites.csv` by migration behaviour — content-invariant, structure-
dependent, substrate-bound, wording-bound — and compute per-system and
per-slot fragility rates to test the repo's qualitative claim that "the
morphology survives; its carriers do not".

**Mechanism / rationale (2–3 sentences).** [idea] `diversity.md` §7 asserts
carrier-independence from two cases (Estonia, Brazil) and never measures it,
yet this is the claim that matters for digital archives: if a large share of
requisites is substrate-bound (Garuda-stamped paper, physical seal, blank-space
rank) or wording-bound (Francophone formula banks, Saudi rank grammar), then
"morphology survives migration" is true only for the boring slots. A four-way
rubric applied row-by-row yields a fragility profile per tradition — a
preservation-risk statement the atlas can make that no page-format standard
makes.

**[assumption] Assumptions.**
- A1: a four-way rubric can be fixed in advance and applied to 225 rows by one
  coder; internal check = blinded re-coding of a random 50-row sample after a
  delay, with agreement reported (no inter-rater kappa is possible solo —
  disclosed, matching the repo's existing single-coder caveats).
- A2: "migration" is defined before coding as paper → structured digital (and
  any subsequent format change), so judgements are about a stated event, not
  vague portability.
- A3: `local_term` / `gloss_en` / `note` carry enough signal for most rows;
  rows that don't are re-read against their case file rather than guessed.

**[prediction] Predicted observations.**
- P1: stem-content rows (S2, S5, S10/S11 substance) are ≥90%
  content-invariant.
- P2: the divergence-heavy categories — substrate authority-marks (S4 on
  stamped stock), rank-by-blank-space, formula banks — are ≥70% fragile.
- P3: authentication (S12) carries the largest fragility share *among stem
  slots* (signature/seal/hanko/tughra/attestation → cryptographic), despite
  being the most universal slot (17/25, `analysis/findings.md` §1) — a
  universality-versus-portability tension worth reporting either way.

**What would disconfirm it.** [prediction] Fragility rates failing to separate
stem from surface (small or reversed gap) disconfirms P1/P2; S12 scoring no
more fragile than other stem slots disconfirms P3; and if coding agreement on
the delayed re-code is low, the rubric itself is disconfirmed and the idea
degenerates into a qualitative essay — which the repo's ledger discipline
should then refuse to publish as a finding.

**Main feasibility risk.** Subjectivity of "would survive a migration" and the
English-gloss caveat in `analysis/findings.md` §6 (many `local_term` cells hold
a gloss, so substrate cues may already be lost in the data); mitigation is the
pre-declared rubric, the delayed re-code, and an explicit `uncodable` class.
Compute: trivial; a small Python pass plus a hand-coded CSV, weeks.

**Repo connections.** `requisites.csv` (225 rows, the whole dataset) ·
`diversity.md` §7 (the claim under test), §4 (scalars), §10a (substrate-bound
S4) · `analysis/findings.md` §1, §6 · `morphology.md` §2 (slot definitions) ·
`cases/ee.md` (already quotes the claim), `br.md`, `th.md`, `sa.md` ·
`analysis/recompute.py` (fragility rates become a new derivable figure, or a
declared hand-coded table).
**Not already done (checked):** searched *.md for fragil/carrier/survives/
migration/serializ — the claim appears as prose in `diversity.md` §7 and
`cases/ee.md` only; no file codes requisites by anything except slot,
obligation and genre (the 9 CSV columns), and no preservation variable exists.

## P07-4 — The record-unit ladder: does the accountable object predict which regime dimensions a system legislates?

**[idea] One-sentence statement.** Code all 28 systems on the level of their
accountable record unit (page document / file / series-fonds / automatic log)
and test whether that level predicts which of the three regime dimensions —
trace, access, persistence/appraisal — the system's legal order legislates.

**Mechanism / rationale (2–3 sentences).** [idea] `diversity.md` §6 shows the
accountable unit can sit one level above the document (India's CSMOP file with
its four-part anatomy), and §10b shows regimes add three dimensions the 14
slots cannot carry — but nobody has asked whether the two are connected: the
archival hypothesis is that you can only legislate appraisal or access *about a
unit larger than one page*, because a single document has no life to govern.
That reframes the atlas's genre-vs-nation question as unit-level-vs-nation: if
unit level outpredicts nation for the three dimensions, the "record unit" is
doing real explanatory work.

**[assumption] Assumptions.**
- A1: unit level can be coded from case files with one fixed rule — "what
  object does the regime make registrable/responsible?" — without new sources.
- A2: the three regime dimensions can be coded presence/absence per system
  from existing prose (hand-coded, disclosed like the regime classes).
- A3: ~5 of the 28 are boundary/regime cases (khipu, wampum, ZA, SE, HN) that
  must be `n/a` on at least one axis, leaving ~23 usable pairs.

**[prediction] Predicted observations.**
- P1: every system legislating access or appraisal sits at unit ≥ file/series
  (NG, KE, ZA, SE, IN) — page-document systems (DE, JP, TH, SA, BR) code 0 on
  both.
- P2: trace (S14-heavy regimes: UA, SU, TH) is reachable at *document* level,
  because trace is about one document's movement; so trace dissociates from
  access/appraisal.
- P3: Estonia's automatic log counts as a high-level unit carrying trace
  without appraisal (`diversity.md` §10d calls it "durable but out of human
  view").

**What would disconfirm it.** [prediction] A single page-document-unit system
that legislates access or appraisal falsifies P1; a permutation/exact test
showing unit level unrelated to dimension presence falsifies the explanatory
claim (P1–P3 jointly); finding trace only at file-level or above falsifies P2's
distinction.

**Main feasibility risk.** Hand-coded narrative judgement on a small n, with
several `n/a` cells — power is limited and the honest output may be an exact
count table rather than an inference; the boundary cases must be pre-declared
excluded rather than quietly dropped. Compute: trivial (permutation test in
Python, minutes).

**Repo connections.** `diversity.md` §6, §10b, §10d · `cases/in.md` (the file
as accountable object), `ng.md`, `ke.md`, `za.md`, `se.md`, `ee.md` ·
`analysis/findings.md` §3 (regime classes and coding density by class) ·
`requisites.csv` (S14 rows as the trace-side data) · `morphology.md` §8 ("the
file as a unit larger than the document").
**Not already done (checked):** searched *.md for fonds/provenance/record
unit/accountable — §6 and `cases/in.md` raise the point once for India; no
cross-system coding of record unit exists in `analysis/`, and no analysis
cross-tabulates unit level against the three dimensions.

## P07-5 — Evidence-tier stress test: does the universal stem survive on primary-anchored systems only?

**[idea] One-sentence statement.** Freeze the per-case grounding tiers the
README already discloses into a machine-readable column, then recompute the
headline structural claims (universal-stem membership, the S6⊥S9 fork, S12 as
the modal slot) on the strong-primary subset alone, to test whether the
universality claim is robust to — or dependent on — the corpus's thin
secondary-grounded cases.

**Mechanism / rationale (2–3 sentences).** [idea] The repo is unusually honest
that grounding tiers differ (strong anchors UA, CN, IN, BR, SA, TH, ID, VN, BJ,
SE, SN, SU vs thin PE, HN, ET, WA — `README.md` Honest gaps; 15/60 sources are
encyclopedic, `analysis/findings.md` §5) but no analysis ever *conditions* on
that, so the caveat can be neither quantified nor dismissed. Because
`analysis/recompute.py` already rebuilds every figure from frozen data and
fails on drift, a tier-restricted specification is a small, fully
ledger-compatible extension in the project's own method style — and either
outcome moves belief: replication upgrades the caveat to a robustness note,
non-replication bounds the scope claim.

**[assumption] Assumptions.**
- A1: the tier labels exist per case file as prose and can be frozen into a
  CSV column *before* running the recomputation (no post-hoc tiering).
- A2: the primary-anchored subset still contains enough slot-coded systems for
  the complementarity counts to mean something (README lists ~12 strong
  anchors; some are regimes or page-slotless, so expect roughly 8–10 usable).
- A3: with that n, the decision rule must be exact counts (violations,
  membership), not asymptotic p-values.

**[prediction] Predicted observations.**
- P1: the S6⊥S9 complementary distribution holds with zero violations on the
  primary-only subset.
- P2: S12 remains the modal slot in the subset (it is currently 17/25).
- P3 (the challenge direction, equally acceptable): at least one member of the
  currently "universal stem" drops below full membership once thin cases are
  removed — i.e. some universality was carried by secondary evidence.

**What would disconfirm it.** [prediction] Any S6/S9 co-occurrence in the
primary subset falsifies P1 and would require re-scoping the fork finding;
loss of a stem slot falsifies P3's negation (i.e. confirms tier-dependence);
full replication on all three falsifies P3 instead and downgrades "grounding
tiers differ" from an honest gap to a measured robustness result.

**Main feasibility risk.** Subset size — strong anchors include page-slotless
regimes (ZA) and boundary cases, so the usable n may be small enough that the
output is an exact-count table with wide-open uncertainty; the honest failure
mode is "informative but underpowered", which must not be sold as confirmation.
Compute: minutes (one new flag + subset branch in `analysis/recompute.py`).

**Repo connections.** `README.md` Honest gaps (tier list) ·
`analysis/evidence_base.csv` · `analysis/findings.md` §5, §7 ·
`analysis/recompute.py` (the second gate to extend) · `ledger.json` ·
`morphology.md` §5 (findings 1–3 being re-tested) · `EXECUTIVE_SUMMARY.md`
(verification paragraph).
**Not already done (checked):** searched *.md for tier/subset/robustness/
sensitivity — "grounding tiers" appears only as a disclosure in `README.md`
and `EXECUTIVE_SUMMARY.md`; `analysis/` contains no tier column, and no
reported figure is computed on a restricted subset.

## P07-6 — Record life beyond writing: do the khipu and wampum have trace, access and appraisal regimes?

**[idea] One-sentence statement.** Ask of the two non-documentary boundary
systems the *archival* question rather than the morphological one — did their
record systems govern custody (trace), who may hear/see them (access), and what
is kept, repaired, retired or destroyed (persistence/appraisal)? — to test
whether the atlas's three regime dimensions are document-independent while its
14-slot grammar is document-bound.

**Mechanism / rationale (2–3 sentences).** [idea] The khipu and wampum
currently serve only to *bound* the slot claim (`diversity.md` §5, §12e:
"authority does not require writing"), and the three regime dimensions were
derived exclusively from written-document regimes (`diversity.md` §10b). If the
two boundary systems show record-life governance without any slots, the atlas
gains a sharper two-layer model — grammar scoped to writing, governance of the
record not — which strengthens the scoped universality claim by showing the
scope line was drawn in the right place; if they show neither, the three
dimensions must themselves be re-scoped as document-dependent.

**[assumption] Assumptions.**
- A1: documentary sources sufficient for a presence/absence coding are
  retrievable within existing constraints (two relevant source texts are
  already in `sources/`; the rest would be ordinary retrieval, no budget).
- A2: the three dimensions can be operationalised without smuggling in
  document vocabulary — access = who may hear/recite/view; appraisal = what is
  preserved, transmitted, retired or lost; trace = marks of custody/handling
  and re-presentation events.
- A3: the specified scope is documentary research only, so no new human
  participants are involved.

**[prediction] Predicted observations.**
- P1: each boundary system codes presence on ≥1 dimension (custody/persistence
  at minimum — `diversity.md` §10d already documents custody models and their
  fragility, including the 4,203 Timbuktu manuscripts burned).
- P2: the wampum codes a trace-equivalent (recitation/transfer events as the
  record's custody marks), while the khipu codes an appraisal-equivalent only
  if evidence of deliberate retirement/destruction of cords is found.
- P3: neither system yields slot-like structure under the 14-slot rubric —
  replicating §5's boundary rather than eroding it.

**What would disconfirm it.** [prediction] If no dimension can be evidenced for
either system *without importing document concepts*, the three dimensions are
themselves document-bound and finding 10b needs re-scoping — that is the sharp
falsifier. Conversely, if slot-like fixed positional structure were evidenced
in khipu encoding, §5's boundary claim would erode. "Not evidenced" must be
reported as absence-of-evidence, never as evidence-of-absence.

**Main feasibility risk.** Thin, secondary source base and real interpretive
drift risk: the same three concepts are easy to read *into* an oral/custodial
practice. Mitigation: operational definitions frozen before coding, an explicit
`not evidenced` state, and reporting the coding as exploratory. Ethics: not
required as specified (documentary only, no participants); **any community-
engaged extension with Haudenosaunee or Andean knowledge-holders would be
flagged 'ethics review required'** and would then be gated. Compute: trivial.

**Repo connections.** `diversity.md` §5 (boundary), §10b (three dimensions),
§10d (custody models), §12e (authority without writing) · `cases/pe.md`
(khipu), `cases/wampum.md` · `README.md` + `EXECUTIVE_SUMMARY.md` (the scoped
universality claim this stress-tests) · `analysis/theme_matrix.csv`
(non-documentary boundary = 2 files) · `STANDARDS.md` Layer 4 (lifecycle vs
records continuum — the theoretical fork this probes from the data side).
**Not already done (checked):** searched *.md for fonds/provenance/record unit
and for retention/appraisal — the boundary cases are handled morphologically
only (§5, §12e, `cases/pe.md`, `cases/wampum.md`); no file applies the
trace/access/appraisal dimensions to them, and the three dimensions are
explicitly derived from the African/Asian written regimes alone.
