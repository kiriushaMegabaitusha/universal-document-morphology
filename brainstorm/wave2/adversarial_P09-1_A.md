# Adversarial review — P09-1 (reviewer A, wave 2)

**Idea ID:** P09-1 — "Validity, not reliability: can the 14-slot deep grammar be re-induced from the requisites themselves?"
**Reviewer:** A (AI, disclosed; originated none of the ideas under review).
**Round rules observed:** no literature search (prior-evidence section is `not-checked`); no reading of other reviewers' outputs (`brainstorm/*/adversarial_*`, `raw/review_*`), `lineage/RESULTS.md`, `PLAN.md`, `brainstorm/wave2/RESULTS.md`, `scores.csv`, `matrix.json` or any results file. Repo data files (`requisites.csv`, `morphology.md`, `analysis/*.csv`) were read to ground the attack.
**Lens assigned:** construct validity.

A note on the numbers below. I ran throwaway stdlib reproductions of the proposed pipeline (no sklearn/numpy on this rig) purely to measure **specification sensitivity**, not to produce a finding about the atlas. They are crude — random-init Lloyd's k-means, no SVD, no k-means++ — so every ARI I quote should be read as a *lower bound on the spread*, not as the design's result. The spread is the argument; the level is not.

## P09-1

**Strongest version of the idea.** The atlas's entire epistemic posture is that reliability is not validity, and its slot-coding instrument has exactly one coder. P09-1 asks the one question the project has never asked: are the 14 slots **discoverable in the material**, or merely **applicable to it**? If S1–S14 are functional categories, they should leave a lexical fingerprint even in the terse analyst glosses, because `morphology.md` §2 defines each slot functionally ("S6 destination — the addressee"; "S9 setting — justification, recitals, legal basis") and any glosser applying those definitions independently should converge on the same vocabulary. If instead the codebook is a Procrustean grid, the glosses will share vocabulary only where the gloss *is* the slot name, and the residual structure will track genre or system instead. The test is cheap (frozen CSV, CPU-only, weeks), pre-registerable, and — the claim goes — has an informative null. The S6/S9 by-product, if it held, would be corroboration by a route that cannot inherit the fork, which is precisely the kind of evidence the project lacks.

Read generously, that is the best case: a *redundancy check on the codebook's own prose*, upgraded into a validity claim. The upgrade is where it breaks.

**Observation that would count against it.** The idea's stated falsifier is ARI/NMI indistinguishable from the fixed-margin null at every frozen k. That is the wrong observation to pin the review on, because — see below — that bar is so low it is nearly unfalsifiable in the other direction. The observation that actually counts against the design is cheaper and more damaging: **a positive ARI that is concentrated in rows whose gloss is a restatement of the slot name or an exact duplicate string.** If the recovered clusters at the best-scoring specification are populated by "Body"→S10, "Subject"→S8, "Seal/Electronic signature"→S12, "Addressee"→S6, while S9 dissolves into a heterogeneous residual, then the reported ARI measures the analyst's habit of naming things after their slot, not the grammar's recoverability. Second, and equally disqualifying: **a positive ARI accompanied by failure of the idea's own branch prediction.** Both happened in my reproduction (details below).

**Alternative explanations (four).**

1. *Nominal fallacy — the gloss is a restatement of the definition.* 32 of 201 core rows (15.9%) share a ≥5-character stem with their own slot name; `S10-body` → "Body", `S10-body` → "Body text", `S13-annex` → "Annex", `S8-subject` → "Subject line", `S2-identifier` → "Unique document identifier", `S7-reference` → "Reference line". The median gloss is 19 characters; 139 of 201 (69%) are ≤3 words; 47 are a single token. This is not a corpus of descriptions, it is a glossary of labels. Recovery from a glossary of the codebook's own terms is a tautology, not evidence.

2. *Duplication, not structure.* 18 gloss strings repeat and cover 50 rows (24.9%). Every repeated string except one maps to a single slot. Any clusterer with a nearest-neighbour core will place those 50 rows correctly for free. In my reproduction the highest-ARI solution's cleanest clusters are exactly these: a 7-row cluster that is 7/7 `S8-subject` built from {"Subject", "Subject line", "Document type and subject summary"}; a 15-row cluster that is 14/15 `S12-authentication` built from {"Seal", "Signature", "Electronic signature", "Seal imprint"}; a 3-row cluster that is 3/3 `S13-annex` built from "Dispatch slip" ×2. That is not the deep grammar re-emerging; it is string identity.

3. *Genre/system style, not slot.* Glosses were written one system at a time, and system row counts are wildly unequal (1 to 32; five systems contribute ≤2 rows). A cluster solution can track drafting-register vocabulary — "Seal", "Imperial monogram", "hanko to e-signature" are IS/JP register — and ARI against slot will pick up part of that because slot and genre are weakly but genuinely coupled. The proposed system-margin null does not fix this: it changes the null, not the estimand. The design needs ARI **against system** reported alongside, so a reader can see whether the solution recovered systems, slots, or nothing.

4. *Hindi/BN: "the fork was never in the data to be found."* `morphology.md` §3 defines the epistolary declension as filling S6 and the normative as filling S9 — the two declensions are constituted *by* which of these two slots is filled. So S6-rows and S9-rows are disjoint by construction of the labels, and a row-level clusterer can only ever rediscover that addressee-words and recital-words differ. The claim that the fork could "reappear without being seeded" is not a prediction about the document world; it is entailed by §3. Worse, the real fork is a statement about the system × slot matrix (zero systems filling both — I verified: 0 of 28), and a clustering of *rows* cannot represent mutual exclusivity at all. This is a level-of-analysis error, discussed as (2) in the lens section.

**Measurement or analysis failure.**

- *The null bar is trivial; the confirmation rule is therefore near-automatic.* I computed the permutation null for ARI between the true slot vector and a random partition with the same 14-class margins at n = 201: mean −0.0001, **SD 0.0073, p99 = 0.0197**. An ARI of 0.069 is ~9 SD above the null — p ≪ 0.001 in a permutation test — while recovering **7% of pair structure above chance**. The design's positive criterion ("clearly above both nulls") is satisfied by an effect that is substantively nothing, and its negative criterion ("indistinguishable from the null") requires ARI < ~0.02, a bar almost no non-degenerate clustering fails. The decision rule is asymmetric in exactly the direction that manufactures confirmations. **An absolute ARI floor must be pre-registered**; null-exceedance cannot carry the inference.
- *The decision rule omits the case that actually arises.* The idea states two predictions (ARI above null; the declension separates as branches). It states a disconfirmer only for ARI. In my reproduction the highest-ARI specification satisfied prediction 1 and **falsified prediction 2** — the 3 `S9-setting` rows did not form a cluster at all; they were absorbed into a 37-row grab-bag spanning 11 slots. A pre-registration with no rule for "significant ARI, branch prediction false" will report the first number and bury the second.
- *"Align clusters to S1–S14" is undefined for k ≠ 14.* Hungarian alignment presupposes equal cardinality; the k-grid explicitly includes k ≠ 14. At k = 10, which slots share a cluster? At k = 20, which slots split? ARI alone does not need alignment (it is label-invariant), so the alignment step is either redundant or an unregistered post-hoc choice — and the proposal mixes ARI (symmetric, chance-corrected pair counting) with Hungarian matching (asymmetric, k-dependent) as if they were one statistic.
- *One genuine coding inconsistency will be charged to the method.* The string "letterhead" is coded to two different slots (`S3-origin`, `S4-authority-mark`; 3 rows). Whatever the clusterer does with those rows, ARI is penalised, and the penalty is an artefact of the codebook's own ambiguity, not of the glosses' informativeness. The "Addressee"/"Addressee" rows and the "Issuing organ" / "Issuing agency" / "Issuing-organ mark" trio are the same problem in milder form. This is the specific cell where the test bites and where a reader will misattribute the loss.

**Sampling or generalizability failure.** The proposed analysis set is not the vocabulary: `requisites.csv` has **225 rows over 20 slot categories**, not 201 rows over 14. The 24 non-core rows (`meta-structure` 10, `rank-modifier` 4, `mixed` 3, `infrastructure` 3, `structural` 2, `access` 2) touch **15 of 28 systems**, and one system (RU) has *no* core rows at all — its only entry is "Approx. 30 requisites (list not retrieved)". So the choice of analysis set silently decides which systems exist for the purpose of the test, and the rows excluded are precisely the ones where the 14-slot vocabulary visibly fails: BR "Page numbering", CN "Red separator line", JP "Layout rules for standard documents", IS "Prestige marker (scalar)", IN "File: correspondence/notes plus appendices". Excluding them removes the cases that would disconfirm content validity, and biases the retained set toward the European, slot-legible core — the metropolitan-axis problem the atlas flags elsewhere. Keeping them, conversely, requires a fixed 15th "off-vocabulary" class. Either way this is a load-bearing decision that the proposal does not mention, and it must be pre-registered. My recommendation is to include all 225 with an explicit `other` class: that is the only version in which a low ARI is interpretable as *the vocabulary over-segments* rather than as instrument failure.

### Construct-validity audit (assigned lens)

**(1) Same analyst wrote `gloss_en` and assigned `slot` — so what does lexical recovery establish? Nothing, if the analysis is run on `gloss_en`.**

The gloss is not an observation of the document independent of the codebook; it is a summarising description written by the person who had already read the slot definitions in `morphology.md` §2 and had to place the row. The row-level co-authorship of gloss and label is certain even if the writing order is not. Therefore a positive ARI is jointly consistent with (a) the slots are real and lexically manifest, (b) the analyst writes glosses using the slot's vocabulary, (c) both — and the design has **no statistic that separates them**. A negative ARI is jointly consistent with (d) the slots are imposed, (e) the analyst's glossing style is heterogeneous, (f) the clusterer is inappropriate. So the experiment is *observationally equivalent* under the hypothesis and its negation: **neither outcome identifies the quantity the idea names.** That is not a scoping weakness; it is a failure of identification, and it is fatal to the framing before any k is chosen.

The framing error compounds it. ARI against a *fixed* partition that the analyst also authored is a mono-method consistency measure — a reliability statistic with a chance correction. Calling it "validity, not reliability" is precisely backwards: the design re-runs the reliability question on a different pair of the same analyst's outputs and re-labels the answer. Standard validity would need a criterion *outside* the codebook: content validity (independent expert judgement of what the requisite is), criterion validity (does the slot partition predict a documented outcome), or convergent/discriminant evidence (does it correlate with what it should and not with what it should not). None is present.

*Cheapest real fix (this is the one that rescues the idea):* a **blind re-gloss subsample**. Take a stratified sample of ~50 core rows, strip the `slot` and `gloss_en` columns, and have a second party — a colleague, or an LLM call of the kind the repo already runs cheaply through OpenRouter — produce a one-line English gloss from `local_term` + clause number alone, **blind to slot and blind to the existing gloss**. Run the identical pipeline on the blind glosses. Now a positive ARI is evidence that *a label-blind describer's vocabulary recovers the slot*, which is a real, if weak, validity signal; and a null is attributable to the description level rather than to the codebook. Cost: an hour and cents. Without this, condition (1) is unsatisfiable.

A partial, free version of the same fix already exists in the data and should be reported as a diagnostic even if the blind re-gloss is not run: **cluster `local_term` alone.** It is a quotation, not analyst prose — the one column not authored in the codebook's metalanguage. In my reproduction it carries essentially no recoverable slot signal (ARI 0.003–0.007 across k). That is an honest and important negative: it says the lexical signal lives entirely in the analyst's English, which is exactly the circularity being denied.

**(2) The S6/S9 by-product cannot count as independent corroboration — three separate reasons, any one sufficient.**

- *Structural:* §3 of `morphology.md` defines the declensions by which of S6/S9 is filled. The fork is an axiom of the codebook, not an observable in the row data. A clustering of rows labelled by slots cannot test a relationship between slots.
- *Level of analysis:* the fork's content is "no system fills both" (verified: 0 of 28 systems do). That is a property of the system × slot matrix. A partition of 201 requisites has no representation of a system, so it cannot express, let alone corroborate, mutual exclusivity. The most a row-clustering can show is that two groups of rows use disjoint vocabulary — which is true of any two disjoint slot sets, fork or not.
- *Empirical:* in my reproduction, at the specification with the highest ARI, the S9 rows did **not** separate. All three (`Justification/recitals`, `Legal-basis citations`, `Recitals (whereas clauses)`) fell into one 37-row cluster spanning 11 slots. S6 partly separated (8 of 11 in one cluster). So the "declension branch" prediction did not just fail to corroborate — it failed, at the specification that looked best. And S9 has **n = 3 rows from 2 systems** (UN, EU — both supranational legal-act drafting). Three rows cannot form a "stable branch" under any resampling scheme; the cluster would have to be declared out of scope before the run, not after.

This by-product is doing most of the rhetorical work in the idea's novelty paragraph. It should be **deleted**, not repaired. The declension can be tested at the right unit (the system × slot matrix with an exact null) but that is a different study, and it is not this one.

**(3) Freezing the k-grid and preprocessing relocates the forking path; it does not remove it. I measured the relocation.**

The proposal's mitigation is "freeze the vocabulary (tokens, stopwords, n-gram range, linkage, k grid) in a config file before any cluster is inspected". That makes the choice *blind*, not *irrelevant*. Here is the spread across textbook-defensible choices I ran on the same 201 rows, same labels, same ARI:

| specification | k | ARI vs slot |
|---|---|---|
| word TF–IDF, k-means | 10 | 0.042 |
| word TF–IDF, k-means | 14 | 0.069 |
| word TF–IDF, k-means | 20 | 0.060 |
| word TF–IDF, average linkage, cosine | 14 | **−0.001** |
| char-3-gram TF–IDF, average linkage, cosine | 10 | 0.082 |
| char-3-gram TF–IDF, average linkage, cosine | 14 | **0.190** |
| `local_term` only, k-means | 14 | 0.003 |

Range: **−0.001 to 0.190.** The spread across specifications is larger than any effect the study could plausibly claim, and it straddles the question: two of these specifications would be reported as "indistinguishable from the null" (a disconfirmation) and one as a strong positive. Freezing picks one cell of this table by lottery before looking. The k-grid does not help because the k-grid itself is a second lottery layered on the first, and because the paper's headline number has to come from one k anyway.

This is a live forking path with a name: **at 69% of glosses being ≤3 words, the choice of word vs character n-grams is not a nuisance parameter, it is the mechanism.** Word n-grams see 283 distinct tokens over 201 documents and most pairs are lexically orthogonal; character trigrams see shared morphology ("addressee"/"addressing", "annex"/"annexes") and manufacture similarity that word features cannot. The one specification that produces a publishable ARI is the one that partially repairs the terse-gloss problem by fuzzing it — i.e. the specification that is *most* duplication-driven. That is not a coincidence to be averaged over; it is the finding.

*Cheapest fix:* (i) make k = 14 the **single primary** analysis, since 14 is the hypothesis, not a free parameter, and report the grid descriptively; (ii) make the confirmatory statistic the **maximum ARI over the grid, with the null distribution of that maximum** (a max-statistic permutation null), so grid-shopping cannot manufacture significance; (iii) publish the full table above with the primary number and pre-commit that if the across-specification range exceeds the observed-minus-null gap, the result is declared specification-dependent and **no inferential claim is made**. This is the same instrument the repo already respects as a sensitivity gate.

**(4) The null conflates "uninformative" with "disconfirming", and the idea's disconfirmation clause makes that conflation the whole test.**

The stated disconfirmer is: ARI indistinguishable from the null at every frozen k ⇒ "the grammar is an imposed classification". But an ARI at the null is equally produced by glosses that simply carry no usable lexical signal — and the data show that is a live possibility: median gloss 19 characters, 47 single-token glosses, 24.9% of rows inside duplicate strings, one string ("letterhead") spanning two slots. A null result therefore has (at least) two incompatible readings — *the codebook is arbitrary* and *the measurement substrate is too thin* — and the design contains nothing that separates them. Publishing "the grammar is an imposed classification" off a null would be an overclaim of exactly the kind the idea exists to prevent.

The confound is empirically visible, not hypothetical: a plain 1-nearest-neighbour over token Jaccard on the same glosses gets slot right **61.7%** of the time against a 15.4% majority-class baseline. So lexical slot signal *does* exist in `gloss_en`; if the unsupervised pipeline returns ARI ≈ 0, the correct inference is "ARI + k-means is the wrong instrument for 2-word documents", not "the deep grammar is imposed". The idea's disconfirmation rule would report the latter.

*Cheapest fix:* two controls, both stdlib-cheap, both pre-registered as part of the decision rule.
- **Supervised ceiling (leave-one-system-out).** Multinomial NB or logistic regression on the identical features predicting `slot`, cross-validated by system (not by row — the system-level split is what makes it comparable to the population claim). Pre-register a floor (e.g. macro-F1 ≥ 0.40 or balanced accuracy ≥ 2× chance). If the supervised ceiling does not clear the floor, the input is declared uninformative and **a null ARI is not counted as disconfirmation** — the study reports "insufficient lexical signal", full stop.
- **Shuffled-gloss negative control.** Permute `gloss_en` across rows (keeping slot labels) and re-run the whole pipeline. ARI must collapse to the null. This catches a clusterer that manufactures structure from the marginal token distribution or from cluster-size imbalance.

**(5) ARI against a fixed partition is the wrong target, because the "true" partition is the object under test — but the fix is not to abandon ARI, it is to make it compete.**

Criterion validity requires a criterion the hypothesis does not contain. `slot` is the hypothesis. ARI(clusters, slot) therefore cannot measure correctness, only redundancy — and it is a redundancy measure with a *known* upward bias here, because the glosses were written under the same definitions the labels encode. Whatever the number, its interpretation is bounded above by "the analyst was consistent".

The repair is cheap and turns a weak test into a sharp one: **run the same embeddings against three criteria and report the triad.**
- ARI vs `slot` — the hypothesis.
- ARI vs `system` — the confound (did it just recover drafting register?).
- ARI vs a **pre-registered coarse genre collapse** — the competing criterion. This matters because `genre` as stored is unusable raw: **31 levels for 201 rows**, including a 29-row catch-all coded `all`, plus five single-row levels. It must be collapsed *in advance* (my suggestion: correspondence / legal-act / other, with the mapping written down and committed). The horse race is meaningful because slot and genre are near-orthogonal at row level — I measured ARI(slot, genre) = 0.035 and ARI(slot, coarse genre) = 0.024 — so a clustering that beats chance on genre but not on slot is a genuine substantive result ("the latent structure of requisite descriptions is genre, not slot"), and one that beats chance on slot but not genre supports slot-specific recoverability.

Without this triad, the design has one number whose reference class is the thing it is testing, which is why the "validity" label cannot be earned at any ARI value.

**Prior evidence that challenges it.** `not-checked — no search this round` (the evidence wave has run; nothing here rests on a novelty claim). What a later check would need to look for: (a) prior "recoverability of an imposed annotation scheme from its own glosses" demonstrations — i.e. whether this design is a known tautology in the ontology-evaluation literature; (b) ontology-evaluation practice on internal versus external criterion validity, specifically whether label-recovery is ever accepted as validity evidence; (c) evidence on clustering short/terse label-like strings, where the known failure is that n-gram choice dominates; (d) any prior attempt to re-induce a diplomatics slot taxonomy from descriptions, which would bear on both novelty and expected ARI.

**Potential harm, inequity, or misuse.** Low direct harm: no participants, no new data, all frozen repo artefacts. Misuse vectors are interpretive and asymmetric: (i) a published ARI "confirming recoverability" would be quotable as "the 14-slot grammar was independently validated", when the analysis only shows the analyst's glosses match the analyst's labels — a validity claim the evidence cannot carry, and one that would be very hard to retract once in a README headline; (ii) the mirror risk, a published null read as "the atlas's taxonomy is arbitrary", is equally unfalsifiable in the other direction and would damage the project's headline claims on the strength of a measurement failure; (iii) the analysis-set choice (dropping the 24 off-vocabulary rows, which touch 15 systems) quietly re-centres the atlas on its European slot-legible core while presenting itself as a test of the whole vocabulary — a de-centring claim resting on a de-centring-in-reverse sample.

**Mitigation.** Blind re-gloss subsample for the primary test; delete the S6/S9 by-product; single primary k = 14 with a max-statistic null over any grid; an absolute ARI floor plus the two controls of (4); the three-criterion ARI triad of (5); include all 225 rows with an explicit off-vocabulary class; publish the full specification table with the headline number; and audit the freeze (config file + hash + timestamp committed before the run, gate-checked like the audit's pinned hashes) so "frozen before inspection" is verifiable rather than asserted.

**Residual uncertainty.** Two things cannot be repaired inside this design. First, even a blind re-gloss is still generated from `local_term`, and *which clause the analyst chose to quote* is itself a slot-informed decision — so the circularity is reduced, not eliminated, and the residual channel is exactly the one that selects "Addressee" as the local term for an S6 row. Second, the terse-gloss substrate may simply be too thin for any induction test: with a 19-character median and 283 distinct tokens, the honest prior is that the true ARI is small and the specification spread is large, which means the study's most likely outcome is an uninterpretable mid-range number. Neither is resolvable without new description at a different grain, which is a different project.

**Disposition: revise.** Do not pause. The question is the right one and the data are already on disk, but as specified the design cannot answer it: a positive is uninterpretable, a null is ambiguous, the headline by-product is a level-of-analysis error, and the frozen grid relocates rather than removes the forking path. It becomes a real validity test only after the construct is re-anchored on a label-blind criterion and the decision rule is made symmetric and grid-invariant.

**Required conditions before any pre-registration could be accepted.**

1. **Blind re-gloss is the primary analysis.** The confirmatory test runs on glosses written by a party blind to `slot` and to the existing `gloss_en`, for a stratified sample of ≥50 core rows (stratified to include ≥2 rows from each of S6, S9, S11 and ≥5 from each of the four largest slots). Analysis on the original `gloss_en` is reported as a *secondary* consistency check, explicitly labelled reliability-of-glossing, and may not be described as validity in any output. If the blind re-gloss is not run, the word "validity" must be removed from the title and the study reframed as a lexical-consistency audit.
2. **The S6/S9 by-product claim is deleted.** No corroboration-of-the-fork language may appear in the pre-registration, the analysis or the write-up. If the author wants to test the declension, it must be a separate registration operating on the system × slot matrix, with the mutual-exclusivity claim as the unit of analysis, and with S9's n = 3 rows / 2 systems declared out of scope in advance.
3. **Single primary k = 14; any k-grid is descriptive only, and any confirmatory grid statistic is a max-statistic with its own null.** The pre-registration fixes k = 14 as the hypothesis-derived primary, and if a grid is used the reported p-value must come from the permutation distribution of the *maximum* ARI across the grid, not from the best cell.
4. **An absolute ARI floor is pre-registered, with the permutation null's scale published.** State the floor (e.g. ARI ≥ 0.20) and state explicitly that null-exceedance alone is not a positive result. The pre-registration must include the null's SD and p99 at n = 201 with 14 classes so that a reader can see how trivial the null bar is (my reproduction: SD 0.0073, p99 0.0197).
5. **The supervised ceiling and shuffled-gloss controls of (4) are part of the decision rule.** Pre-register the leave-one-system-out supervised floor; if it is not met, the outcome is recorded as "insufficient lexical signal" and may not be reported as disconfirmation of the grammar. Pre-register the shuffled-gloss negative control's expected null.
6. **The three-criterion ARI triad is mandatory and equally prominent.** Report ARI vs `slot`, ARI vs `system`, and ARI vs a pre-registered coarse genre collapse whose full mapping is written and committed before any run (raw `genre` has 31 levels including a 29-row `all` catch-all and is not usable as-is). The pre-registration states in advance how a genre-win or system-win will be interpreted, and commits that a genre-win counts against the slot-recoverability claim.
7. **Analysis set = all 225 rows with an explicit off-vocabulary class.** No silent drop of the 24 non-core rows; the pre-registration names the class and states how ARI treats it. Sub-analyses on the 201 core rows may be reported as sensitivity, but the primary set is the full table, so that the vocabulary's own failures are inside the test rather than excluded from it.
8. **The full specification table is published with the headline number, and a specification-stability gate is pre-committed.** Report ARI for every combination of {word, char n-gram} × {k-means, average linkage} × the frozen k-grid. Pre-commit that if the across-specification range exceeds the observed-minus-null gap, the result is declared specification-dependent and no inferential claim is made. On my reproduction that gate fires (range −0.001 to 0.190).
9. **The gloss-level diagnostics are reported as results, not footnotes.** Number of duplicate-gloss rows, number of glosses restating their own slot name, number of single-token glosses, and the `letterhead`-type cross-slot strings must appear in the paper beside the ARI, together with an ARI recomputed after removing the duplicate-gloss rows. These are the cells where the test bites and where a reader will otherwise misattribute a low ARI to the grammar.
10. **The freeze is auditable.** The config is committed with a hash and timestamp before the run and checked by a gate, in the style of the audit's pinned hashes; the pre-registration states that the analysis script reads only the committed config. "Frozen before inspection" is unverifiable as currently described.
11. **The decision rule covers the case that actually occurs.** Pre-register the interpretation for (significant ARI, branch prediction false) — as observed in my reproduction. As written, the rule has no cell for the most likely outcome, which is how a headline forms after the fact.
12. **No output may use the phrase "independently validated".** The strongest permitted claim, pending an external criterion beyond a label-blind re-gloss, is that slot-consistent vocabulary is recoverable from label-blind descriptions of the requisites — a statement about descriptions, not about documents, and not about the correctness of the 14-slot partition.
