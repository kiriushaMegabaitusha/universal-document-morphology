# Case: India — Central Secretariat Manual of Office Procedure (CSMOP)

- **Instrument:** the Central Secretariat Manual of Office Procedure, the
  Government of India's nodal rulebook for secretariat work (16th edition,
  2022), issued under the Department of Administrative Reforms and Public
  Grievances [S-CSMOP, C29].

## The unit of record is the *file*, not the document

CSMOP makes this explicit: a file may consist of "one or more of the following
parts with a file number" [S-CSMOP, C30]:

1. **Correspondence portion**
2. **Notes portion**
3. **Appendix to correspondence portion**
4. **Appendix to notes portion**

Key issues arise in the Appendix to Notes and are then processed in the Notes
portion with a cross-reference to the relevant page — i.e. the file is a
*deliberation substrate*, not a container of finished documents.

## File numbering is a classification system

Two systems: a **functional file number** developed by DARPG, an alpha-numeric
code for basic / primary / secondary levels (a faceted classification), and the
older **conventional file number** based on subject [S-CSMOP, C31]. In the
electronic file system (eFile), the file and receipt numbers are appended by
the system automatically [S-CSMOP, C32].

## The standard communication forms

The manual fixes "standardized forms of communication": the **letter**, the
**D.O. letter** (demi-official, personal), the **office memorandum** (internal),
the **endorsement**, the **notification**, the **U.O. note** (unofficial), plus
telegraph, and — later editions — email [S-CSMOP, C33]. Drafting has its own
chapter with procedure and general instructions [S-CSMOP].

## The point for the atlas

India contributes a **meta-structure**: the file, which contains documents and
is itself the accountable record. The atlas's slot model is document-centric;
CSMOP shows that the recordkeeping unit can be one level up — the file — with
its own four-part anatomy and its own identifier grammar (the functional file
number). The "note" (deliberation) is a document genre with no European
equivalent in the sample: a document whose whole purpose is to argue to a
decision-maker.
